REGLAS IMPLEMENTADAS
- Proteínas y vegetales son metas mínimas.
- Superar proteínas o vegetales no genera alarma.
- Frutas, harinas y grasas deben coincidir con la meta para que el día esté completo.
- Exceder frutas, harinas o grasas genera alerta roja.
- Cumplir el plan exige cumplir todos los grupos.
- Guardado automático con cada cambio.
- Un registro por fecha; los cambios editan el mismo registro.
- Meta personal de ejercicio de 0 a 7 días por semana.
- Progreso semanal de 7 días terminando en la fecha seleccionada.
- Reporte de 4 semanas consecutivas terminando en la fecha seleccionada.
- Los cambios de plan crean un nuevo plan desde la fecha elegida y no alteran el historial.
- Todo se guarda localmente en el dispositivo.

PARA ACTUALIZAR GITHUB
1. Elimina o reemplaza los archivos actuales del repositorio.
2. Sube el contenido de esta carpeta conservando las subcarpetas css, js y assets.
3. Haz Commit changes.
4. Espera a que GitHub Pages termine de desplegar.
5. Abre Tina y actualiza la página.
